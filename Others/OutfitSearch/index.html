CONNECTION

Cloudflare Worker

OutfitSearch needs the included Worker because Roblox blocks these requests from a normal GitHub Pages tab.

FIVE STEPS

Deploy the Worker

  1. Create.Cloudflare → Workers & Pages → Create Worker.
  2. Replace.Open Edit code and replace the starter file with this package’s worker.js.
  3. Deploy.Save the Worker and copy its public .workers.dev URL.
  4. Connect.Paste that URL into OutfitSearch’s API dialog.
  5. Optional.Put the URL in the outfit-api-base meta tag so visitors never see setup.

Never paste Cloudflare tokens, Roblox cookies, or GitHub tokens here. OutfitSearch does not need them.
