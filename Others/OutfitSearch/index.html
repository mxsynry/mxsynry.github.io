Public Roblox avatar lookup

Roblox Outfit Viewer

Look up public accounts by username or user ID, compare duplicate-looking accounts, and list current avatar items plus saved outfits.

API setup

This GitHub Pages app needs a small Cloudflare Worker because many Roblox API calls are blocked by browser CORS. Paste your Worker URL once and it will be saved locally in this browser.

Tip: you can also append ?api=https://your-worker.workers.dev to the page URL. Use the Change API button if you saved the wrong URL.

Supports comma/newline separated values. Use id:12345 for exact ID. Use search:keyword to show possible matching accounts.

Simple setup instructions

  1. Open Cloudflare → Workers & Pages → Create application → Worker.
  2. Name it something like roblox-outfit-api, then deploy the starter Worker.
  3. Click Edit code, delete the starter code, paste this project’s worker.js, then Save and deploy.
  4. Copy the public URL ending in .workers.dev, for example https://roblox-outfit-api.yourname.workers.dev.
  5. Come back here, click Change API, paste that Worker URL, and click Save API.

Do not paste a Cloudflare API token, Roblox cookie, GitHub token, or your GitHub Pages URL. Only paste the public .workers.dev URL.
