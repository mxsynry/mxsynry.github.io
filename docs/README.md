- Synchrose: `https://mxsynry.github.io/Others/Synchrose/`

- Project scope and architecture
- Source provenance matrix

## Maintenance rule

When an integration or source policy changes, update both the documentation and `source-audit.json` in the same pull request. Do not add an endpoint unless its owner documents or explicitly permits public use.
