CONNECTION

Cloudflare Worker

Your browser talks to one Worker. The Worker requests public Roblox data and, when enabled, Rolimons market metadata.

SETUP

Deploy the Worker

  1. 01Create a Worker in Cloudflare Workers & Pages.
  2. 02Replace the starter code with this package’s worker.js.
  3. 03Deploy and copy the public .workers.dev URL.
  4. 04Connect that URL in OutfitSearch.
  5. 05Choose provider mode. Rolimons-first reduces Roblox item-metadata fallbacks; Full Roblox uses the richer fallback chain.

Rolimons-first does not replace Roblox username, avatar-state, thumbnail, or saved-outfit endpoints.
