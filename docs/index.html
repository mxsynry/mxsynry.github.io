Synchrose docs

A Svelte catalog combining WEAO, Voxlis, Pulsery and bypass.tools.

Architecture

Adapters fetch and normalize each source, then merge matching records for the UI. Source failures keep the last successful data.

Cloudflare builds include the API bridge. Static hosts fall back to dated catalogs, marked cached. Browser snapshots expire after 24 hours.

Model

Types: Others/Synchrose/src/lib/catalog/model.ts.

Each record holds normalized fields, source observations and conflicts. Unknown values use null. Retrieval times and source update times are separate.

Merging

  • Match normalized names using the alias table.
  • Keep each source observation and platform variant.
  • Show conflicting values with their source.

Validation

Adapters validate payloads, URLs and score ranges. Markdown uses DOMPurify. The bridge has fixed GET routes; review credentials stay in the Worker environment.

Changes

Update the adapter and its fixture together. Run the checks before deployment.
