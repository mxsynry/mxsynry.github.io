Public Roblox avatar lookup

Roblox Outfit Viewer

Look up public accounts by username or user ID, compare duplicate-looking accounts, and list current avatar items plus saved outfits.

API setup

This GitHub Pages app needs a small Cloudflare Worker because many Roblox API calls are blocked by browser CORS. Paste your Worker URL once and it will be saved locally.

Tip: you can also append ?api=https://your-worker.workers.dev to the page URL.

Supports comma/newline separated values. Use id:12345 for exact ID. Use search:keyword to show possible matching accounts.
