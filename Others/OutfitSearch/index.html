Setup guide

Worker setup

  1. Cloudflare → Workers & Pages → create a Worker.
  2. Deploy it once, then open Edit code.
  3. Replace the starter code with this project’s worker.js.
  4. Save/deploy and copy the public .workers.dev URL.
  5. Paste that URL here with Change API.

Only paste the public Worker URL. Do not paste Cloudflare tokens, Roblox cookies, or GitHub tokens.
